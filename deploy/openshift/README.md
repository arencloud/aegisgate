Cluster resources are generated by `scripts/render-openshift.py` into the git-ignored
`deploy/generated/openshift.json`. JSON is a valid Kubernetes manifest format.

The generator includes Keycloak and its realm, Redis, all three application workloads,
service accounts, Gateway/HTTPRoute, a backend waypoint, RHCL AuthPolicy, a Coraza
WasmPlugin, backend mesh authorization policies, and Redis ingress isolation.

See [the deployment guide](../../docs/openshift.md) for prerequisites, installation,
and the checks required to validate the requested RHCL 1.5 / Service Mesh 3.5 combination.

The application-specific [Coraza configuration](coraza-waf.yaml) uses the pinned
`quay.io/arencloud/coraza` image, blocking mode, and 64 KiB request-body limits.
Its namespace and gateway match AegisGate. The renderer includes the same settings
and supports `WAF_MODE` and `CORAZA_IMAGE_PULL_SECRET` overrides. No cluster apply
has been performed.
